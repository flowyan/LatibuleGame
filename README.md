# Latibule Game Project

This is a game project called "Latibule". It is a work in progress game and engine.

Currently all parts of the LatibuleGame are in one repository for ease of development, but in the future they may be split into separate repositories and use git submodules.

The Latibule Engine is a custom game engine developed for the LatibuleGame using OpenTK 4.

## Mallet Editor
![mallet editor icon](/Editor/Assets/icon.jpg)<br>
Mallet is a map/level editor for the Latibule Engine. It allows users to create and edit game levels.
